# FrameSaur — downloads & updates

This repo only hosts release builds of **FrameSaur** (customizable Spotify now-playing frames with a floating desktop widget and OBS overlays). The installed app checks here for updates automatically.

**Get it:** open the [latest release](https://github.com/garyzd04/FrameSaur-releases/releases/latest) and download

- `FrameSaur-Setup-x.y.z.exe` — installer (recommended; updates itself), or
- `FrameSaur-Portable-x.y.z.exe` — single-file portable build (no auto-update).

Windows only. Source lives in a separate repository.
