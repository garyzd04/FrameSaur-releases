Full setup guide
  1. Desktop app? You're already set — skip to step 2. Browser version? Put this file next to Start FrameSaur.bat and double-click the .bat; it serves the app at http://127.0.0.1:8888 (needs Python from python.org).
  2. Go to developer.spotify.com/dashboard, log in with your regular Spotify account, and click Create app.
  3. Name it anything (e.g. FrameSaur). In Redirect URIs, paste the exact URL shown in this panel. Tick Web API and save.
  4. Open the app's Settings, copy the Client ID, and paste it into the field here.
  5. Click Connect Spotify and approve. That's it — this PC stays connected.

Friends: in your dashboard app, open User Management and add each friend's name + Spotify email (development mode allows up to 25 people). Then share the folder — or host the same file on any https site (like GitHub Pages) and register that URL as a second redirect URI.
